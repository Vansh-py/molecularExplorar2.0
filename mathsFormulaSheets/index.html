Class 11 & 12 Maths Formula Compilation

Class 11 – Trigonometric Functions

  • sin²θ + cos²θ = 1
  • 1 + tan²θ = sec²θ
  • 1 + cot²θ = cosec²θ
  • sin(-θ) = -sinθ, cos(-θ) = cosθ, tan(-θ) = -tanθ
  • sin(2θ) = 2sinθcosθ, cos(2θ) = cos²θ - sin²θ, tan(2θ) = 2tanθ / (1 - tan²θ)
  • sin(A ± B) = sinA cosB ± cosA sinB
  • cos(A ± B) = cosA cosB ∓ sinA sinB
  • tan(A ± B) = (tanA ± tanB) / (1 ∓ tanA tanB)
  • sin(3A) = 3sinA - 4sin³A, cos(3A) = 4cos³A - 3cosA
  • Product to Sum:
    sinA sinB = ½[cos(A−B) − cos(A+B)]
    cosA cosB = ½[cos(A−B) + cos(A+B)]
    sinA cosB = ½[sin(A+B) + sin(A−B)]

Class 12 – Inverse Trigonometric Functions

  • Principal Values:
    sin⁻¹x ∈ [−π/2, π/2]
    cos⁻¹x ∈ [0, π]
    tan⁻¹x ∈ (−π/2, π/2)
    cosec⁻¹x ∈ [−π/2, 0) ∪ (0, π/2]
    sec⁻¹x ∈ [0, π] \ {π/2}
    cot⁻¹x ∈ (0, π)
  • Identities:
    sin⁻¹x + cos⁻¹x = π/2
    tan⁻¹x + cot⁻¹x = π/2
    sec⁻¹x = cos⁻¹(1/x)
    cosec⁻¹x = sin⁻¹(1/x)
    tan⁻¹x + tan⁻¹y = tan⁻¹((x+y)/(1−xy)), if xy < 1
  • Conversions:
    2tan⁻¹x = sin⁻¹(2x / (1 + x²)) = cos⁻¹((1 − x²) / (1 + x²))

Class 12 – Matrices

  • A + B = [aᵢⱼ + bᵢⱼ], A − B = [aᵢⱼ − bᵢⱼ]
  • kA = [k·aᵢⱼ]
  • AB = [Σ aᵢₖ·bₖⱼ]
  • Transpose: (Aᵗ)ᵢⱼ = Aⱼᵢ
  • (AB)ᵗ = BᵗAᵗ, (Aᵗ)ᵗ = A
  • A is symmetric if Aᵗ = A, skew-symmetric if Aᵗ = −A
  • I: Identity matrix, O: Zero matrix
  • A is invertible if det(A) ≠ 0

Class 12 – Determinants

  • |A| = determinant of A
  • For 2x2: |A| = ad − bc
  • For 3x3: Use cofactor expansion across any row/column
  • Properties:
    |Aᵗ| = |A|
    If two rows/cols are identical → |A| = 0
    Multiplying row by k → det is multiplied by k
    If one row is multiple of another → det = 0
  • adj(A) = Transpose of cofactor matrix
  • A⁻¹ = adj(A)/|A|, if |A| ≠ 0
  • Area of triangle = ½ |x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)|
  • Cramer's Rule:
    x = |A₁| / |A|, y = |A₂| / |A|, z = |A₃| / |A|
